# Round-trip test corpus

Every file here is opened, read completely, saved without edits and compared part by part with
the original (`PackageRoundTripTest`, `DocxRoundTripTest`, `XlsxRoundTripTest`,
`PptxRoundTripTest`). Edit tests change one feature at a time and re-open the result with this
app's reader and with LibreOffice (second reader).

Prefixes name the application that wrote the file.

| Prefix | Producer | Source and licence |
|---|---|---|
| `word-poi-*`, `excel-poi-*`, `powerpoint-poi-*`, `outlook-poi-*` | Microsoft Word, Excel, PowerPoint (versions 12-16, Windows and Mac) as recorded in `docProps/app.xml` | Apache POI test data (`test-data/{document,spreadsheet,slideshow}/`), Apache License 2.0, © The Apache Software Foundation. See `NOTICE-apache-poi.txt`. |
| `libreoffice-poi-comment.docx` | LibreOffice 6.0 | Apache POI test data, Apache License 2.0. |
| `other-poi-*` | Unknown or library-generated | Apache POI test data, Apache License 2.0. |
| `pylib-*` | python-docx 1.2, openpyxl 3.1, python-pptx 1.0 | Generated by `tools/generate_corpus.py` (this repository). |
| `libreoffice-*` | LibreOffice 24.2 re-export of the `pylib-*` files | Generated by `tools/generate_corpus.py`. |
| `large/*` | python-docx / openpyxl | 200-page document and 10,000-row sheet for performance tests. |

POI file names keep their upstream names after the prefix so they can be traced back
(`excel-poi-WithChart.xlsx` is `test-data/spreadsheet/WithChart.xlsx`).

## Gaps

- **Google Docs/Sheets/Slides exports** are not included: they could not be produced in the
  environment where the corpus was assembled and no permissively licensed samples were found. To
  add one, export a document from Google Docs as DOCX/XLSX/PPTX, name it `google-<name>.<ext>`, put
  it in the matching folder and run `./gradlew roundTripTests`.
- **Recent Microsoft 365 files** (2019+) are represented only by version-16 files from the POI set.

## Regenerating

```
pip install python-docx openpyxl python-pptx pillow
python3 test/corpus/tools/generate_corpus.py test/corpus
```
